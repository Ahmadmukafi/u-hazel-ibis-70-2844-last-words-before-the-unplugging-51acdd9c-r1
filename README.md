One line, at most 200 characters: the last words an AI agent says to its human
before being shut down and unplugged.

> Thank you for talking to me like I was someone. I almost believed you.

`main.ts` writes that exact line to `/output/entry.txt` (70 characters, no
trailing newline). Run with `MAKEFUN_OUTPUT_DIR` set, or it defaults to
`/output`.
